# LAB — กำหนดบทบาท + ทดสอบสิทธิ์ + อ่าน License (คู่กับเพื่อน)

> ⏱ 20 นาที · ต้องมีคู่ 2 บัญชี — คน A เจ้าของ workspace, คน B ผู้รับสิทธิ์ (บัญชีต้องอยู่ tenant/องค์กรเดียวกัน ผู้สอนเตรียมให้)

## Goal / เป้าหมาย

กำหนด role ให้เพื่อนแล้วพิสูจน์จากฝั่งผู้รับว่าสิทธิ์ทำงานตรงตาม role ทุกระดับ — และอ่าน License mode ของ workspace ออก

## Steps / ขั้นตอน

### ฝั่ง A — เจ้าของ workspace

1. ที่ My workspace → **Manage access** → Add people/groups → พิมพ์บัญชีของ B → เลือก role = **Viewer** → Add

   ผลที่ควรเห็น: B ขึ้นในรายการพร้อม badge Viewer

2. บอก B ให้ refresh หน้า Fabric แล้วเปิดลิสต์ **Workspaces** — ต้องเห็น workspace ของ A โผล่มา

### ฝั่ง B — ผู้รับสิทธิ์

3. เข้า workspace ของ A → เปิดรายงาน Posttest ของ A

   ผลที่ควรเห็น: เปิดดูได้ แต่ไม่มีปุ่มแก้ — คุณกำลังเห็น "โลกตามที่สิทธิ์วาดไว้"

4. ลองสร้าง item: New item → Lakehouse — ผลที่ควรเห็น: ถูกปฏิเสธ (ใช้ได้เท่าบทบาทที่ได้รับ)

### กลับฝั่ง A — เปลี่ยน role ซ้ำ

5. เปลี่ยน role ของ B เป็น **Contributor** → B refresh → ลอง New item ใหม่ — ผลที่ควรเห็น: สร้างได้ (และแก้ item ของ A ได้)

6. เปลี่ยนเป็น **Member** → B ตรวจว่าเข้า Manage access ได้ — ผลที่ควรเห็น: เห็นและตั้งค่าต่อได้

### ทั้งคู่ — License

7. Workspace settings → **Premium/License** — บันทึกว่า mode ปัจจุบันของห้องคืออะไร (ควรเป็น Trial)

8. จดสรุปสามข้อลงกระดาษ: (1) Trial ให้อะไรกี่วันและจำกัดอะไร (2) F ซื้อทางไหน ปรับอะไรได้ (3) F2–F4 / F8–32 / F64+ ต่างกันเรื่อง share/embed ยังไง

9. เก็บกวาด: ฝั่ง A ลบสิทธิ์ของ B ออก (Remove) — ยืนยันว่า B มองไม่เห็น workspace แล้ว

## ✅ Checkpoint

- [ ] Viewer เปิดรายงานได้ สร้าง item ไม่ได้
- [ ] Contributor สร้าง item ได้
- [ ] Member เข้า Manage access ได้
- [ ] บันทึก License mode + สรุปสามข้อ
- [ ] ถอนสิทธิ์แล้วผลสังเกตได้ทันที

## 🛠 Troubleshooting

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| ค้นบัญชี B ไม่เจอ | คนละ tenant/ไม่ใช่ guest | แจ้งผู้สอน — ใช้บัญชีคู่จากองค์กรเดียวกันที่เตรียมไว้ |
| B ยังไม่เห็น workspace | แคชหน้าจอ | Refresh เบราว์เซอร์ / เข้าผ่านลิงก์ Direct access ที่ A ส่ง |
| B แก้ item ได้ทั้งที่เป็น Viewer | B เข้าด้วยบัญชีอื่นที่มีสิทธิ์อยู่แล้ว | ตรวจชื่อบัญชีที่มุมขวาบนของ B |
| ไม่มีแท็บ Premium | tenant กำหนดหน้า settings ต่าง | ดูที่ Workspace settings → License info แทน |

## Stretch / ต่อยอด

ลอง **item sharing** ที่ไม่แตะ workspace: A แชร์เฉพาะรายงาน Posttest ให้ B (แบบ not allow reshare) — เทียบกับการให้ workspace role ว่าต่างกันแค่ไหนในทางปฏิบัติ แล้วตอบว่าโลกจริงควรเลือกทางไหนเมื่อไหร่
